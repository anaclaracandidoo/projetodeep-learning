# 📚 EduAcessível

👨‍🏫 Objetivo do projeto

O EduAcessível tem como objetivo auxiliar os professores na organização de seus materiais e no planejamento didático do semestre.

📂 Como funciona?

A proposta é utilizar os dados presentes nos materiais disponibilizados pelos professores para organizar as informações de forma clara e estruturada.

📚 Organização das disciplinas

O sistema irá identificar e organizar as matérias, seus conteúdos e a respectiva linha de ensino, facilitando a elaboração do planejamento para todo o semestre.

📅 Planejamento semestral

Com as informações organizadas, o professor poderá ter uma visão mais clara dos conteúdos que serão trabalhados durante o período letivo, facilitando a distribuição e o acompanhamento das atividades.

✨ Benefícios

O EduAcessível busca tornar a rotina dos professores mais organizada, prática e eficiente, reduzindo o tempo gasto com a organização dos materiais e permitindo que o docente tenha mais facilidade para planejar suas aulas.

🎯 Em resumo: o projeto busca transformar materiais e informações dispersas em um planejamento didático organizado e acessível, auxiliando o professor durante todo o semestre.
